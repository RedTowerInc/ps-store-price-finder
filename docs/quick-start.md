# Запуск PS Store Price Finder

## Сборка

[Скачать версию 0.1.120 для Windows](https://github.com/RedTowerInc/ps-store-price-finder/releases/tag/v0.1.120).

Нужны Windows 10/11 x64 и доступ в интернет. Установка Python не требуется.

1. Распакуйте ZIP в отдельную папку.
2. Оставьте `_internal` рядом с `PSStorePriceFinder.exe`.
3. Запустите `PSStorePriceFinder.exe`.

## Что посмотреть за несколько минут

1. Найдите игру по названию, например `diablo`.
2. Сравните предложения Украины и Турции: цены, скидки и подписочные признаки.
3. Посмотрите пересчёт стоимости в тенге.
4. Сузьте выдачу локальным фильтром.
5. Добавьте нужный товар в избранное и настройте столбцы таблицы.

Сборка подготовлена без пользовательских настроек, истории поиска и сохранённых сессий. При запуске приложение создаёт собственные рабочие файлы.
